# Priyansh Das — Portfolio

A responsive, static portfolio about hospitality, food, software and the curiosity that connects them. It uses semantic HTML, CSS and plain JavaScript, with no build step or site dependencies.

## Preview locally

From the project folder, run node preview-server.cjs. Then open http://127.0.0.1:5500/index.html.

## Photos

The three supplied photos have been edited for tone and exposure, then saved as optimized JPEGs in the assets folder. The original downloads were left untouched. The generated PNG masters remain in the Codex generated-images folder.

## Before publishing

- Confirm the current education status and dates.
- Review the project descriptions and links.
- Confirm the contact email and public profile links.

Google Fonts load when online; local system fonts are used as fallbacks. The site does not publish changes by itself.

## Publish

This folder is intended for the root of the priyanshdas.github.io GitHub Pages repository. Copy or commit the site files there when ready.
